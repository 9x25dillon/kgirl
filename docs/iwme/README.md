# iwme: the IWME Phase 0–3 verification bench

`src/kgirl/iwme/` turns the IWME-PRIME-01 audit into code. It rebuilds IWME
Draft 1.0 and the four supplied sources as computable objects, repairs the core
architecture, and checks every number in the report
`research/iwme/IWME_Phase0-3.pdf` with a 62-claim registry. A refuted source
claim appears as a passing check: each check asserts what the computation shows.

```
draft claim or source equation
        │
        ▼
module function (attention, cascade, irt, wake, sources, core)
        │
        ▼
registry check Vnn (verify.py) ──▶ CLI, MCP tool, unit tests
        │
        ▼
report: text, five figures, Appendix A (generated table)
```

## Layout

- `src/kgirl/iwme/`: the package. numpy throughout; sympy for V23 and V41
  (skipped with a note when absent); matplotlib for the figures.
- `tests/iwme/`: 70 unit tests. One skips when `kgirl.main`'s optional
  dependencies are absent.
- `research/iwme/IWME_Phase0-3.tex` and `.pdf`: the report (24 pages).
  `verification_table.tex` is generated by the registry; never edit it by hand.
- `research/iwme/figures/`: the five figures, generated by `plot`.

## Commands

```bash
export PYTHONPATH=src
python -m kgirl.iwme verify                       # 62 checks, about 20 s
python -m kgirl.iwme source-e [--data bins.csv]   # Source E checks V48–V62; optional G_E bins (Q2_GeV2,GE,sigma)
python -m kgirl.iwme verify --fast                # 44 checks, about 4 s (drops V08, V19, V33)
python -m kgirl.iwme verify --only V22 V26        # selected ids
python -m kgirl.iwme verify --json                # machine-readable
python -m kgirl.iwme verify --latex research/iwme/verification_table.tex
python -m kgirl.iwme irt --phi 2.5 --psi 1.7 --kernel damped
python -m kgirl.iwme attention --T 0.8 --rho 0.5
python -m kgirl.iwme cascade --p 0.7
python -m kgirl.iwme persist --c 0.5 --rho 0.3 --memory ema
python -m kgirl.iwme plot -o research/iwme/figures
python -m unittest discover -s tests/iwme -t .    # 70 tests, about 14 s
(cd research/iwme && latexmk -pdf IWME_Phase0-3.tex)
```

`verify` exits 1 if any check fails, so it can gate CI.

## MCP tools

The harness MCP server (`kgirl.harness.mcp_server`) exposes three tools:

- `iwme_verify` (`fast`, default true; `only`, e.g. `"V22 V26"`): runs the
  registry and returns the rendered report.
- `iwme_irt_point` (`phi`, `psi`, `kernel` = `damped` or `constant`, `k0`): the
  corrected induced metric with its mixed component, the published Appendix A.1
  metric, det g, Jacobian rank, scalar curvature, principal curvatures and
  Source C eq. 29 at one chart point.
- `iwme_attention` (`T` > 0, 0 < `rho` ≤ 1): fixed points and multipliers,
  closed-loop retention at H = 0 against the open-loop value, adiabatic
  hysteresis area, and the flip threshold for anti-aligned values.

## Modules

- `core`: the repaired controlled-POMDP core (`IWMECore`), its observationally
  equivalent augmented model, the linear-Gaussian instance (`LinearIWME`) and
  the exact persistence-after-decoupling criterion `R_persist`.
- `attention`: softmax-EMA memory; open-loop and closed-loop sensitivity (P2,
  P2′); the Popoviciu contraction bound; the two-point pitchfork (P3); crossing
  types (P3′); hysteresis; gated forgetting.
- `cascade`: binomial, Markov-modulated and EMA-memory cascades; Rényi spectra
  in closed form, by box counting, by transfer matrix and by transfer operator;
  the Hutchinson fixed point that models Source B's fixed-point claim.
- `irt`: Source C's Inverse Resonant Toroid. Induced metric (closed form,
  Jacobian, symbolic), determinant, rank and singular circles, scalar curvature
  by three independent routes, and the published formulas transcribed for
  comparison.
- `wake`: the damped wave equation of Source B with centered and backward
  damping, CFL limits, temporal order, the exact discrete energy identity, the
  zero-order-hold memory coupling (`HybridWake`), and Source B's PDE claims.
- `sources`: Source D's Walsh–Hadamard, Z9 and Prediction 5 checks;
  phase-coherence measures (Source B eq. 4.10, spectral share, mean resultant).
- `source_e`: Source E's computable claims (E8 roots, octonionic Jordan identity, vortex rings, the proposed
  transport PDE, the dipole radius, modular flow) and `compare_bins` for G_E data.
- `verify`: the registry (V01–V62) with text, JSON and LaTeX renderers.
- `plots`: the report's figures.

## Investigator input applied

- (a) P2 holds for the fixed-input filter. Once the scores read the memory, the
  closed-loop Jacobian is (1−ρ)I + (ρ/T)Cov_a(v,k) and attention sets retention:
  at T = 1.2, ρ = 0.5 the sensitivity of H_10 to H_0 is 0.365 in closed loop
  against 9.8e−4 in open loop (V02).
- (b) The IRT Jacobian has rank 3 except on the circles {ψ = 0, sin φ = 0} and
  {κ = 0, D = 0}, so the induced metric is nondegenerate there (V25). The
  published metric is wrong in g_φφ and g_ψψ and omits the mixed component
  g_φψ (−0.563 at (φ, ψ) = (2.5, 1.7); V24).
- (c) The temperature-controlled bifurcation is an established type (a
  mean-field pitchfork). The program adopts it as the mechanism to build on and
  claims no new physical law.

## Findings by evidence level

Level 0, established mathematics computed here:

- The repaired core separates observation (Π) from actuation (C_E). No
  statistic of the observables distinguishes relational memory from unmodeled
  physical state (Proposition 5; `test_augmented_state_reproduces_observables`).
- Pitchfork at T_c = 1 with H* ≈ T√(3(1−T)); critical decay H_t√t → √(3/(2ρ))
  (1.731982 against 1.732051); hysteresis area 0.658, 0.173, 0.0111 at
  T = 0.6, 0.8, 0.95 with measured exponent 1.975 against 2; a flip at
  T_f = ρ/(2−ρ) for anti-aligned values (V06–V13).
- Closed-loop retention at H = 0 is 41.5, 5.48, 2.47 steps at T = 1.05, 1.5, 3
  and tends to −1/ln(1−ρ) = 1.443 (V03).
- The IRT scalar curvature takes both signs (67% negative and 33% positive for
  κ ≡ 1), so Source C's "negative curvature" is false; its eqs. 16, 28 and 29
  fail (V29–V32).
- Source B: a false defect identity, a coherence equation that leaves [0, 1], a
  Lagrangian that generates a different field equation, and a first-order time
  scheme whose CFL limit shrinks with γΔt (V33–V41).
- Source D: the reported Walsh coefficients belong to a different input, the
  Z9 check cannot fail, and Prediction 5 rewards smoothness (V43–V45).
- R_persist is exactly 0 under H1, 1.366 bits with actuation, ~1e−14 given
  (X, H), and separates an EMA memory from an accumulator by its lag profile
  (V47).

Level 1, extrapolation: the gated-forgetting and memory-cascade variants
describe classes of physical systems (V14, V19).

Level 2, hypothesis requiring experiment: an attention–memory class with
temperature T and write rate ρ predicts held-out behaviour of a physical system
better than hidden-state models of matched dimension and information access;
C_E ≠ 0 as extension M4.

Level 3, speculative: presence beyond state incompleteness; any reading of the
IRT as a communication device.

## Determinism

Every variate comes from `kgirl.evolve.chaos.ChaosRNG` (logistic map). The
package imports neither `random` nor `numpy.random`, so every run reproduces
exactly.
